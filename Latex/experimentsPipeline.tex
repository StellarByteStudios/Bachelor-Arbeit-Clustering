\section{Implementierung der Algorithmen}
    Die Algorithmen wurden alle in C++ implementiert. Für die Flussalgorithmen wird die Open-Source Bibliothek Lemon Graph Library \cite{Lemon-Lib} verwendet. Gesteuert werden sie durch ein Hauptskript, welches über die Kommandozeile bedient werden kann. \newline
    Das Program lässt sich in zwei Modi Kompilieren. Es lässt sich entscheiden ob eine Fortschrittsanzeige auf der Standardausgabe angezeigt werden soll. Dies wurde für die automatischen tests deaktiviert, da das zu Unübersichtlichkeit führt.

\section{Automatisierte Analyse}
    Wie schon zufor genannt sollen die Algorithmen auf einigen Subsamples und mit verschiedener Clusteranzahl $k$ durchgeführt werden. Um ein Subsample auf einem Algorithmus für verschiedene $k$ durchzuführen verwenden wir ein Bash-Skript. \newline
    Um die verschiedenen Subsamples zu testen wird in einem Pythonskript mithilfe von Subprozessen eine Shell aufgebaut und für jedes Sample das Bash-Skript aufgerufen. ==== Dann wir alles wieder eingelesen bla bla
